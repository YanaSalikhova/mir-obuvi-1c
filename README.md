# Информационная система для торговой компании «Мир обуви»

## 📌 Описание проекта
Данная информационная система разработана в среде **1С:Предприятие 8.3** (учебная версия) для выполнения задания по учебной практике (УП) по ПМ.02. 
Приложение предназначено для автоматизации работы торговой компании «Мир обуви», ведения каталога товаров, оформления заказов и учета складских остатков.

## 🚀 Основные возможности
1. **Авторизация по логину:** Вход в систему осуществляется по логину из списка пользователей без ввода пароля.
2. **Разграничение прав доступа (Роли):**
   * **Администратор:** полный доступ ко всем функциям (создание, изменение, удаление).
   * **Менеджер:** управление заказами (создание, удаление).
   * **Авторизованный пользователь:** просмотр каталога, оформление заказов (без права удаления).
   * **Неавторизованный пользователь:** только просмотр каталога.
3. **Каталог товаров:** 
   * Отображение моделей обуви с ценами.
   * Встроенный поиск.
4. **Управление заказами:**
   * Создание документа «Заказ клиента».
   * Автоматический подбор цены из карточки товара.
   * Автоматический расчет суммы по строке и итоговой суммы документа.
   * Автоматическое списание остатков при проведении заказа.
5. **Отчетность:** 
   * Встроенный отчет «Остатки на складе», отображающий актуальное количество товаров в реальном времени.
6. **Импорт данных:** 
   * Разработана обработка «Загрузка данных» для импорта пользователей, размеров, категорий, номенклатуры и остатков из файлов Excel.

## 🛠️ Техническая реализация (Объекты метаданных)
* **Справочники:** `Пользователи`, `Категории` (иерархический), `Размеры`, `Номенклатура` (с картинками).
* **Документы:** `ЗаказКлиента` (с движениями по регистру).
* **Регистры накопления:** `ОстаткиТоваров`.
* **Перечисления:** `РолиПользователей`.
* **Обработки:** `ЗагрузкаДанных`, `ВходВСистему`.
* **Отчеты:** `ОстаткиНаСкладе`.
* **Общие модули:** `Авторизация` (проверка логина).
* **Параметры сеанса:** `ТекущийПользователь`, `ТекущаяРоль`.

## 📂 Структура проекта (как запустить)
1. Разверните пустую информационную базу в 1С:Предприятие 8.3.
2. Загрузите конфигурацию из файла `*.cf` (или `*.dt`).
3. Запустите 1С:Предприятие.
4. В окне авторизации введите один из тестовых логинов:
   * `isivanov` (Администратор)
   * `papetrov` (Менеджер)
   * `asidorova` (Авторизованный пользователь)

## ⚠️ Известные ограничения (Учебная версия)
* В связи с ограничениями учебной версии платформы 1С, программное создание фонового рисунка на форме (`ВидПоляФормы.ПолеКартинки`) недоступно. Логотип размещен на иконке приложения.
* Программные отборы динамических списков в каталоге заменены на встроенный механизм поиска 1С из-за особенностей работы учебной платформы.
